Custom units

This tutorial shows how to define your own units. A Unit is defined by its scale relative to the SI unit of its dimension, its exponent map, its dimension and its context. The exponent map is a frozenset of (symbol, exponent) pairs. It identifies the unit and is how the unit is printed. Custom units can be combined with the units of the registry u like any other unit.

{% include code/custom-0.html %}

The dimension of a unit does not have to be one of the predefined dimensions in qunits.dimension. Any dimension can be obtained from the dimension d of a composite unit.

{% include code/custom-1.html %}

Angles are dimensionless units with the context Context.ANGLE. The trigonometric functions np.sin, np.cos and np.tan only accept angles, and quantities with different contexts cannot be added or subtracted.

{% include code/custom-2.html %}

There is exactly one unit per exponent map. Defining a unit again returns the existing unit, and defining a different unit with an existing exponent map raises a ValueError.
