qunits.Unit. to  (  unit  )[source]

Convert the unit into a Quantity in the target unit, e.g. u.km.to(u.m) is 1000.0 m.

Parameters:
unitUnit | None

The target unit, e.g. u.m, or None for the SI unit of the dimension.

Returns:
quantityQuantity

The unit as a quantity in the target unit.

Raises:
ValueError

If the target unit has another dimension or context.

TypeError

If unit is neither a Unit nor None.
