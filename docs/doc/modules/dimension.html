qunits.dimension

The qunits.dimension module contains the dimension definitions for the unit system. A dimension is a vector of the exponents of the seven SI base dimensions, see Dimension. The seven base dimensions are the unit vectors, in this order:

  • Time
  • Length
  • Mass
  • ElectricCurrent
  • Temperature
  • AmountOfSubstance
  • LuminousIntensity

A special dimension is the Dimensionless dimension, which is the zero vector.

  • Dimensionless

The following dimensions are predefined combinations of the base dimensions.

  • Acceleration
  • Action
  • Area
  • Capacitance
  • Charge
  • ElectricField
  • Energy
  • Force
  • Frequency
  • Jerk
  • MagneticInduction
  • Power
  • Pressure
  • Resistance
  • Velocity
  • Voltage
  • Volume

All other dimensions are created when they first appear in unit arithmetic, e.g. the dimension of u.cd / u.m**2, and get generated names such as LuminousIntensity__DIV__Area.
