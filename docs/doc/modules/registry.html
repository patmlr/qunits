qunits.registry

The qunits.registry module provides the unit registry u, which includes all predefined units with prefixes. If you don't want to add custom units, you simply need to import u. 

  from qunits import u

The registry contains the following units, each with the prefixes for powers of 1000 in the given range, e.g. u.fs, u.ps, ..., u.s. The attosecond is u.attosecond, because as is a keyword. u.I is the dimensionless unit.
